# Fullstack Trello Clone
A fullstack application that replicates the core functionality of Trello, allowing users to create boards, lists, and cards, and manage tasks efficiently.

# FE Stack
- React
- TypeScript
- Tailwind CSS
- DND Kit

# BE Stack
- Node.js
- Express
- TypeScript
- Prisma

# Start
```bash
# Client
cd client
npm install
npm run dev

# Server
cd server
npm install
npm run dev

# Start db
docker-compose up -d
```
